# opencode-claude-theme

**Claude Code look for OpenCode Desktop** — a warm charcoal palette, a collapsible
project/session tree, and an OpenCode Go usage-limits footer. One file, no build step.

GUI-плагин для OpenCode Desktop: тёплая «угольная» палитра в духе Claude Code
(тёмно-серый с тёплым подтоном + оранжевый акцент), менее скруглённые углы,
дерево проектов с сессиями и блок лимитов в левом сайдбаре.

![OpenCode Desktop 2.2.x](https://img.shields.io/badge/OpenCode%20Desktop-2.2.x-e8a087)

## Что даёт

- **Палитра Claude Code.** Тёплый тёмный фон `#262624` / `#1f1e1d` вместо
  нейтрального `#161616`, оранжевый акцент `#e8a087` вместо синего, почти
  прямые углы.
- **Дерево проектов.** Проекты с шевронами, вложенные сессии, подсветка активной,
  создание новой сессии из строки проекта. Заменяет нативный плоский список
  вкладок в левом сайдбаре.
- **Лимиты OpenCode Go.** Три полосы — 5 часов, неделя, месяц: сколько процентов
  осталось и когда сбросится окно. Блок скрывается, если подписки Go нет.

## Требования

- OpenCode Desktop **2.2.x** (проверено на 2.2.5) — нужен экспериментальный
  GUI-API плагинов (`@opencode/plugin/gui`).
- Git — для установки из репозитория.
- Подписка OpenCode Go — только для блока лимитов; остальное работает без неё.

## Установка

Клонируйте репозиторий в папку плагинов:

```sh
git clone https://github.com/GG1KENOBI/opencode-claude-theme.git \
  ~/.config/opencode/plugins/claude-theme
```

Пропишите плагин в `~/.config/opencode/opencode.json` (путь должен быть
абсолютным):

```json
{
  "plugins": ["/Users/you/.config/opencode/plugins/claude-theme"]
}
```

Перезапустите OpenCode Desktop. Если приложение уже открыто, можно попросить
его перезагрузить плагины:

```sh
opencode-cli reload
```

В macOS CLI из состава Desktop 2.2.5 лежит здесь:

```sh
"/Users/you/Library/Application Support/ai.opencode.desktop/cli/2.2.5-arm64/opencode-cli" reload
```

`reload` подхватывает новую ревизию файла не мгновенно — приложение опрашивает
ревизию с задержкой в несколько секунд.

## Как это работает

`gui-experimental.cjs` — это GUI-плагин. Десктопное приложение загружает его
через `GET /api/plugin/gui?id=claude-theme`, выполняет default-экспорт и вызывает
`setup(ctx)`. Внутри добавляется один `<style data-plugin="claude-theme">` через
`ctx.add(Style, css)`, а дерево проектов монтируется в сайдбар.

Приложение рисует свою палитру отдельным `<style>` (вставляется *после* плагинных
стилей) и дополнительно задаёт фон `html` инлайново, поэтому все переменные
переопределяются с `!important` и на селекторе `html:root[data-color-scheme="dark"]`.

### Дерево проектов

Нативный вертикальный список вкладок (`[data-titlebar-tab-list]`) скрывается, а на
его месте в `[data-slot="vertical-tabs-scroll"]` рендерится собственное дерево:

- проект — строка с шевроном и количеством сессий;
- сессии вложены под проектом, клик открывает сессию;
- состояние «развёрнут/свёрнут» хранится в `localStorage` под ключом
  `claude-tree-collapsed-v2`;
- при первом запуске разворачивается проект текущей (или самой свежей) сессии;
- «+» на строке проекта создаёт черновик новой сессии в каталоге проекта.

Данные берутся из `ctx.client.project.list()` и `ctx.client.session.list()`
(постранично, только корневые неархивные сессии). Открытие сессии — тот же экшен,
что и клик по вкладке: `ctx.tabs.open({ server, id }, { focus: true })`.

Сайдбар управляется Solid, поэтому дерево периодически проверяет, что оно всё ещё
в DOM, и при необходимости переставляется обратно. Данные обновляются раз в 8
секунд, подсветка активной сессии — чаще. При успешном монтировании в
`renderer.log` пишется `[claude-theme] project tree mounted`, после первой
загрузки лимитов — `[claude-theme] usage limits mounted: …`.

### Лимиты

Внизу сайдбара закреплён компактный блок «Лимиты» (sticky footer дерева): три
полосы OpenCode Go — 5 часов, неделя, месяц. В каждой строке видно, сколько
процентов осталось и когда сбросится окно; наведение показывает точный процент
использования и дату сброса. Полоса заполняется по мере расхода и меняет цвет на
янтарный (≥70%) и красный (≥90% или `limited`).

Данные берутся не со страницы Console, а из того же нативного эндпоинта, которым
пользуется диалог Usage в приложении:

```js
ctx.client.experimental.usage.limits({})
// → { data: { workspace, go: { rolling, weekly, monthly }, budgets } }
```

`go.*.percent` — процент **использованного** лимита (0–100), `resetsAt` —
миллисекунды Unix. API отдаёт только проценты, без сумм в долларах, поэтому блок
показывает остаток в процентах. Обновление — раз в минуту, при возвращении окна в
фокус и по кнопке ↻ (появляется при наведении). Если данных нет (нет подписки Go
или не выполнен вход), блок скрывается.

## Настройка

- Правки палитры — в блоке `css` в начале `gui-experimental.cjs`.
- Стили дерева и лимитов — в `treeCss`.
- Цвета полос лимитов и пороги предупреждений — в функциях рендера блока
  `usage`.

## Диагностика

Логи плагина:

```sh
tail -f ~/Library/Application\ Support/ai.opencode.desktop/logs/*/renderer.log
```

Ищите строки с префиксом `[claude-theme]`. Если дерево не появилось — проверьте,
что в конфиге указан абсолютный путь и что версия Desktop 2.2.x.
